# Reply Copilot：Reddit / X / LinkedIn / Hacker News 回复助手（Chrome 扩展 v0.17.0）

自动发现你感兴趣的帖子和评论，用你的风格起草回复，**由你确认后亲自发送**。

## 安装

1. 到 [Releases](https://github.com/CNTWDev/social-media-copilot/releases/latest) 下载最新的 `reply-copilot-vX.Y.Z.zip`，解压。
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选解压出来的 `reply-copilot` 文件夹。第一次装会自动打开设置引导。
4. 升级：把新版本解压覆盖到同一个文件夹，在扩展页点刷新按钮。数据存在浏览器里，不会丢；也可以先在「设置 → 配置备份 / 迁移」导出一份备份。

也可以直接克隆仓库，用仓库根目录作为「已解压的扩展程序」加载。

**发布新版本（维护者）**：改 `manifest.json` 的 version，在 README 加一节 `## vX.Y.Z 更新：…`，推到 main。GitHub Actions 发现是新版本号，就会自动打包 zip、建 tag 并发布到 Releases，发布说明取自 README 里对应的那一节。

## 它做什么

| 环节 | 做法 | 为什么安全 |
|---|---|---|
| 自动浏览 | ① 你正常刷 Reddit / X 时，屏幕上停留过的帖子、评论、回复会被读取；② 每 45 分钟从你关注的子版块拉一次 Reddit 新帖（公开只读接口，不带登录态） | 不模拟点击、不自动翻页，你的账号行为和平时一模一样 |
| 找到感兴趣的内容 | 关键词初筛 → Claude Haiku 按你的兴趣打 0-100 分；**原帖和评论楼层都会打分** | 只花很少的 API 费用 |
| 起草回复 | 高分内容自动用 Claude Opus 起草 3 个不同角度的草稿，附一句建议；回复评论时会带上「原帖 → 上几层回复」的完整上下文；语言自动跟随原内容 | 草稿只出现在侧边栏 |
| 调整草稿 | 每条下面有「补充要求」输入框（如“更口语一点”“加上我对功耗的看法”“反驳他”），点「按要求重写」；也可以直接在草稿框里改 | — |
| 发送 | 点「填入回复框」→ 扩展打开对应页面、展开回复框、把草稿填进去 → **你自己检查并点平台的发送按钮** | 扩展永远不会替你点发送 |
| 安全阀 | 每日上限（默认 Reddit 15 / X 20）+ 每条之间 3-9 分钟随机冷却，到限后按钮自动变灰 | 避免高频、规律的发帖模式 |
| 风格学习 | 见下文 | — |

## 风格学习（让草稿像你写的）

在侧边栏「我的风格」页：

1. **导入 Reddit 历史评论**：填用户名，一键导入最近约 300 条公开评论。
2. **采集 X 历史回复**：在设置里填好 X 账号，点「打开我的 X 回复页」，往下滑一会儿，你自己的回复会被自动记下。
3. **粘贴样本**：从任何地方复制你写过的回复，用 `---` 分隔。
4. **自动学习**：每次你通过扩展发出回复，它会记录定稿；如果你改过草稿，会记下「草稿 → 定稿」的差异（这是最有价值的信号）。每累计 8 条自动更新一次档案。
5. 点 **「生成 / 更新风格档案」**，Claude 会总结出一份风格档案（语气、长度、用词、不同语言下的差异、你会删掉的东西），你可以直接修改。
6. **观点与立场**：单独一栏，写你的背景和长期观点，起草时参考。以后可以继续扩展。

起草时会同时用到：风格档案 + 观点 + 8 条最相近的历史样本（同语言、同平台优先）+ 最近 5 条修改记录。

## v0.17.0 更新：右键「帮我回复」「帮我翻译」分开

- 右键菜单拆成两项：**帮我回复**、**帮我翻译**。从哪项打开就只做哪件事，不会先生成一遍回复再切到翻译，省 token。
- Chrome 规定一个扩展有两项以上菜单时，会收进以扩展名命名的子菜单，所以现在是右键 → Reply Copilot → 帮我回复 / 帮我翻译。
- 快捷键也一样各管各的：Ctrl/⌘+Shift+9 回复，Ctrl/⌘+Shift+8 翻译。
- 升级后需要在 `chrome://extensions` 点一下刷新，新菜单才会出现。

## v0.16.1 更新：全部数据也能导入

- 「设置 → 数据」新增 **导入全部数据**：用之前「导出全部数据」的文件整机恢复（待回复列表、已发记录、统计、关联库和所有配置），会二次确认；你当前的 API Key 保留。
- 在这里选到的是配置文件时，自动按「合并」方式导入配置。

## v0.16.0 更新：配置一键导出 / 导入，默认配置改为通用

- **导出配置**（设置 → 配置备份 / 迁移）：兴趣、关键词、子版块、HN 关键词、观点、风格档案、风格样本、翻译与修改记录、公司背景、账号、关注名单、观点候选，打包成一个 `reply-copilot-config-日期.json`。待回复列表、统计和缓存不在里面。
- **API Key 默认不导出**，勾选「包含 API Key」才会带上（明文，只放在自己电脑上）。
- **导入配置**：两种方式。「合并」只补空着的或还是默认值的项，列表和样本去重追加，不动你改过的内容；「覆盖」用文件里的替换（会二次确认）。文件里没有 Key 时不会清掉你已有的 Key。
- 首次安装的引导页顶部也能直接导入配置文件，有 Key 的话直接跳到画像页确认。
- **默认配置改成通用的**：仓库里不再内置某个人的兴趣、关键词、子版块、观点和公司资料；新用户通过引导（一段自我介绍让 AI 帮忙整理）或导入配置文件来填。
- **话题分类跟着兴趣走**：兴趣描述里「1. 名称：说明」这样编号的每一行就是一个分类，打分时按这些分类归类；没有编号行时用通用分类（技术、产品、商业……）。
- 升级不会动你已经保存的兴趣、关键词和观点；不再往老配置里合并任何默认内容。

## v0.15.0 更新：首次安装的设置引导

第一次安装后会自动打开一个 5 步的引导页（约 3 分钟），每一步都可以跳过，离开某一步时就会保存：

1. **模型**：选 Claude / OpenAI / DeepSeek，填 API Key，点「测试连接」确认能用；顺便选你的母语。
2. **账号**：填 Reddit / X / LinkedIn / HN 的用户名（可选），用来认出你自己写的内容。
3. **画像**：用几句话介绍自己，点「帮我整理」，AI 会整理出关注的领域、观点与立场、预筛关键词、子版块和 HN 关键词，你可以直接改。
4. **回复风格**：贴几条你以前写的回复，或从 Reddit 导入历史评论，点「生成风格档案」。
5. **开始用**：怎么用侧边栏、工作台、右键和快捷键；点「打开工作台」完成。

以后想重新配置，在「设置」最上面点「打开设置引导」。还没填 Key 时，侧边栏和工作台顶部会提示「开始设置」。

## v0.14.1 更新：右键直接翻译

- 右键菜单这一项改名为「帮我回复 / 翻译」，仍然直接在一级菜单里（Chrome 规定一个插件有两项以上就会收进子菜单，所以合成一项）。
- 小窗顶部切到「翻译润色」，选中的文字会保留并直接翻译；小窗会记住你上次用的功能，上次在翻译，下次右键打开就直接翻译。
- 自动判断方向：选中的是别人的外文 → 翻成你的母语帮你看懂（不润色、不当作你的写作样本）；选中的是你自己用母语写的 → 翻成你选的语言（默认英文）并按你的风格润色。手动换了语言就照你选的来。
- HN 页面上，翻译别人的外文没问题；把你写的内容翻译润色后发到 HN 不允许，小窗会提示。

## v0.14.0 更新：工作台 + Hacker News + 翻译润色

- **工作台**：侧边栏右上角点「工作台 ↗」，在浏览器标签页里打开整页工作台（可以拖到第二块屏幕）。左边是来源与视图（全部来源 / Reddit / X / LinkedIn / Hacker News / 回复我的，以及发帖、翻译润色、关联库、风格、设置），中间是紧凑列表，右边是详情。点一张卡片，右边就显示原文、草稿和重写框，列表不动。
- **侧边栏变轻**：只显示你当前正在看的平台上值得回的内容（顶部写着「当前页面：Reddit」，可以点「看全部」），其他功能都在工作台里。从侧边栏进入讨论后，点「← 回到当前页面」返回。
- **Hacker News**：浏览 news.ycombinator.com 时自动读取你看到的帖子和评论；另外按「设置 → Hacker News」里的关键词定时拉新帖和首页（公开只读接口）。HN 从 2026 年 3 月起规定不允许 AI 生成或 AI 改写的评论，所以 HN 上的内容不起草、不翻译、不填入：点「中文解读」看帖子和评论区要点、以及你可以从哪些角度参与；点「和我讨论」用中文把观点聊清楚，然后打开原帖自己写。右键「帮我回复」在 HN 页面上也不会生成回复。
- **翻译润色**：翻译页改名为「翻译润色」，默认「翻译 + 按我的风格润色」（意思以你的原文为准，但会去掉啰嗦、理顺逻辑，贴着你的说话习惯写），也可以切回「只忠实翻译」；目标语种和原文一样时就是只润色。小工具版本：在任何地方复制文字后按 Ctrl+Shift+8（Mac 是 ⌘+Shift+8），弹出小窗直接翻译润色；小窗顶部也可以在「帮我回复」和「翻译润色」之间切换。你复制走的版本会用来学风格。

## v0.13.0 更新：轻量「帮我回复」小窗（聊天用）

- 右键菜单只剩一项「帮我回复」，直接出现在右键一级菜单里，不用再进子菜单。
- 选中任意网页上的文字（聊天、邮件、评论都行）→ 右键「帮我回复」→ 弹出一个独立小窗，立刻给 3 条聊天语气的回复，每条附中文意思。点「复制」后回去粘贴发送。
- 小窗底部写下你的观点或想说的意思，按 Enter 按你的意思重新生成；右上角可以换回复语言（默认英文，也可以选「对方的语言」、法文等），会记住你上次的选择。
- 桌面聊天软件（微信、WhatsApp、Slack 等）：先复制对方的话，再按 Ctrl+Shift+9（Mac 是 ⌘+Shift+9），弹出同一个小窗。要在 Chrome 没有打开在前台时也能用，到 chrome://extensions/shortcuts 把这个快捷键改成「全局」。前提是 Chrome 在后台运行着。
- 你复制走的回复会用来学语气，改过的地方也会记下来。
- 在 Reddit / X / LinkedIn 上选中的是别人对你帖子的回复时，小窗里多一个「挂到我的帖子下面」按钮（原来那个单独的右键菜单合并到这里了）。

## v0.10.0 更新：回复别人的帖子

- 「发帖」里的议题分两种：**发表我的观点**和**回复别人的帖子**。
- 回复别人：把对方的帖子粘贴进来（作者、链接可选），
- 先用母语讨论：AI 会帮你看懂对方的观点、哪里有道理哪里站不住，并找出值得回应的角度。
- 讨论完点「组织回复」：把你在讨论里的观点和输入，结合对方的帖子，整理成 3 条回复建议，默认英文（可选其他语言），每条附母语意思；可以补充角度再重写，有链接时可以直接填入回复框，发送由你自己点。
- 这类议题也在「历史议题」里，带「回复」标记，点开可以接着讨论。

## v0.9.0 更新：跨语言工作流

- **讨论用你的母语，定稿用目标语言**：设置里新增「我的母语」（默认中文）。发帖的讨论、回复建议、补充要求都可以用母语；最终发出去的内容用目标语言（发帖默认英文，回复默认跟对方一致）。

- **找回**：「历史议题」里新增「已发布的帖子」列表，议题被删掉的也能点开找回内容；删除议题时会提示已发布的帖子不会丢。

## 安装（约 3 分钟）

1. 解压 `reply-copilot.zip`，得到 `reply-copilot` 文件夹（放在一个不会被误删的位置）。
2. Chrome 地址栏打开 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择 `reply-copilot` 文件夹。
4. 点工具栏上的拼图图标，把 Reply Copilot 固定出来；点它打开侧边栏。
5. 在「设置」里：
   - 填入 Anthropic API Key（在 https://console.anthropic.com 创建）。
   - 填你的 Reddit 用户名和 X 账号（用于识别你自己写的内容，不会拿来登录）。
   - 检查兴趣描述、关键词和子版块，点「保存设置」。
6. 去「我的风格」导入样本、生成风格档案。
7. 正常刷 Reddit / X，侧边栏「待回复」会慢慢出现内容。

Edge、Arc、Brave 等 Chromium 浏览器同样适用。
